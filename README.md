# Almaty Air Quality Forecast

Жоба Алматы қаласының атмосфералық ауа сапасын машиналық оқыту әдістері арқылы болжайды және адам денсаулығына төнетін қауіпті бағалайды. Жүйе қала тұрғындарына, соның ішінде астма және жүрек-қантамыр ауруы бар адамдарға арналған.

## Мақсаты
Ауа сапасын болжау және денсаулыққа қауіпті бағалау арқылы тұрғындарға уақытылы ескерту беретін веб-жүйе әзірлеу.

## Пайдаланушылар
- Қала тұрғыны
- Қауіп тобындағы тұрғын (астма, жүрек аурулары бар)
- Экологиялық талдаушы
- Әкімші

## Талаптар
1. Тұрғын қала ауданын таңдап, ауа сапасының ағымдағы деңгейін (AQI) қарайды.
2. Тұрғын келесі 24–72 сағатқа PM2.5 болжамын көреді.
3. Жүйе болжам бойынша денсаулыққа қауіп деңгейін (төмен, орташа, жоғары) бағалайды.
4. Қауіп тобындағы тұрғын өзінің денсаулық профилін көрсетіп, жеке ұсыныстар алады.
5. Талдаушы ауа сапасының тарихи деректерін кесте мен график түрінде қарайды.
6. Әкімші датчиктерден келген деректерді жүктеп, тексереді.
7. Әкімші ML-модельді қайта оқытып, дәлдік көрсеткішін қарайды.
8. Жүйе AQI шектен асқанда тұрғынға ескерту көрсетеді.
